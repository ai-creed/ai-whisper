Store each route as `{ method, segments: string[], handler }`, with `segments` from splitting the pattern on `/` after the leading slash. `match` splits the path the same way and compares segment-wise: a `:x` segment captures a non-empty segment into `params.x`, a `*` segment (only valid as the last pattern segment) consumes one or more remaining segments joined with `/` into `params["*"]`, and any other segment must be equal. A path with a different segment count than a non-catch-all pattern does not match, which keeps trailing slashes a 404. While scanning, remember whether any pattern matched the path with a different method so `match` can return `{ status: 405 }` instead of `{ status: 404 }`. `handlers.ts` exports the moved functions with their original bodies; `server.ts` registers the three routes at module load and maps the `{ status }` results to the existing 404 and 405 responses.

`match.ts` exports `matchTopic(pattern, topic)`: split both on `.` and walk the pattern segments; a `*` consumes exactly one topic segment, a `**` in the last position succeeds when at least one topic segment remains, and any other segment (including a `**` that is not last) is compared literally; the walk succeeds only when both sides are consumed together. `bus.ts` keeps its `Map<pattern, Set<handler>>`. `emit` first collects the exact-topic handlers, then the handlers of every other registered pattern for which `matchTopic` is true (map insertion order), into one snapshot array and only then invokes them, so unsubscribing during delivery cannot skip anyone. `once` registers a wrapper that removes itself in a `finally` block before or around calling the real handler, so a throwing handler is still removed.

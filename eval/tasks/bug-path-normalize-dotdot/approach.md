Split on `/` and track `absolute = p.startsWith("/")`. Walk the segments with a stack: skip `""` and `.`; on `..` pop when the stack top is a real segment, otherwise push `..` if the path is relative, and drop it if the path is absolute and already at the root. Join with `/`, prefix `/` when the path is absolute, and return `"."` for an empty relative result or `"/"` for an empty absolute result.

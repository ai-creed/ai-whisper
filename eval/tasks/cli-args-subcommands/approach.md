Make `parseArgs` a single pass over the tokens with an active flag table that starts as the globals. While no command is selected and `commands` exists, an unflagged positional that names a command selects it and switches the active table to that command's flags merged with the globals (globals win on a name conflict); the selected name is consumed rather than pushed to `positionals`. When a flag is parsed, put it in `flags` if the globals declare it and in `commandFlags` otherwise; a flag missing from the active table throws `unknown flag --name`. Initialise `command: null` and `commandFlags: {}` so the result shape is stable. In `help.ts`, build lines from the spec: a `Global flags:` block, then each command as its name plus help line followed by its flags, using the fixed flag line format `  --name  (type)`. Keep `commands` optional so existing callers compile unchanged.
